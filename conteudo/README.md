# 🎬 Conteúdo — a fábrica de shorts

Este é o espaço onde o guia vira **aula em vídeo**. A ideia do quadro é simples e
repetível:

> **"Pra fazer [efeito], usa esse som."**
> Um som (ou uma técnica) por vídeo curto. Mostra o antes/depois, diz onde pegar, manda
> pro repo.

Cada short documenta, na prática, **uma linha do [catálogo](../guia/4-catalogo.md)** — e o
CTA ("catálogo completo no link") traz a galera pra cá. Gravar a série vai, naturalmente,
preenchendo e divulgando o repositório.

## Como um short vira entrada no catálogo

1. Escolhe um som da [`fila.md`](fila.md) (ou um novo que apareceu).
2. Grava seguindo o template abaixo.
3. Se o som for ✅ e livre, confirma que ele está em `sons-livres/`. Se não estiver,
   linka a fonte.
4. Posta com o CTA pro repo.

## Template de roteiro

Cada roteiro em [`roteiros/`](roteiros/) segue este formato (curto, ~30s):

```markdown
# NNN — <título>

**Som:** <nome no catálogo>  ·  **Selo:** ✅/🚫  ·  **Onde:** 📦 sons-livres/… ou 🔗 fonte

## Gancho (0–3s)
"<frase de abertura que fisga>"

## O ponto (o que ensinar)
- que som é, e em que momento do vídeo ele entra
- por que funciona (1 frase)

## Demo
- antes (sem som) → depois (com som), no mesmo corte

## Como fazer
- CapCut: <1 linha>
- Remotion: <1 linha de código>

## CTA
"Catálogo completo no link da bio 🔊"
```

## Regras do quadro

- **Um som por vídeo.** Não empilha — cada short ensina uma coisa só.
- **Sempre o selo de licença.** É o diferencial: você ensina a não tomar strike.
- **Mostra o antes/depois.** O som só "clica" pra audiência no contraste.
- **Fecha no repo.** O vídeo é a isca; o catálogo é o destino.
