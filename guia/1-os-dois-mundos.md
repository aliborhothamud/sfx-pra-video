# 1 · Os dois mundos (leia antes de tudo)

Existe uma divisão jurídica que decide se você pode usar um som ou não. Ela é simples,
mas quase ninguém explica direito — e é o que separa um vídeo tranquilo de um strike de
copyright. Entenda isto primeiro; o resto do guia depende dela.

## A regra

| | Onde é seguro | Onde é violação |
|---|---|---|
| **Músicas famosas + sons virais** (Thunderstruck, phonk, memes de áudio) | **Dentro do TikTok / Reels / Shorts, adicionado pelo app** — a plataforma tem a licença | Baixar o arquivo e **renderizar** junto do vídeo (ad, entrega pra cliente, YouTube monetizado, postar fora da plataforma) |
| **SFX royalty-free + sons gerados** (whoosh, riser, boom, click, os deste repo) | **Qualquer lugar** — renderizado, ad pago, cross-platform | (nenhum) |

## Traduzindo pro seu fluxo

- **Vai postar orgânico, pelo app?** Pode usar os sons virais à vontade — mas
  **adicione pelo próprio app** (a trilha do TikTok, o áudio do Reels), **não renderize
  junto**. A licença é da plataforma, não sua.
- **Vai renderizar?** (anúncio pago, vídeo entregue pra cliente, YouTube monetizado,
  qualquer coisa que sai como um MP4 seu) → **fique nos royalty-free**. Senão vem strike
  ou desmonetização.

É por isso que, no [catálogo](4-catalogo.md), todo som tem um selo:

- ✅ **Pode gravar ad** — royalty-free ou seu. Renderiza sem medo.
- 🚫 **Só orgânico (copyright)** — o som famoso/meme. Só entra pelo app.

## Os quatro tipos de licença que você vai encontrar

| Licença | O que é | Pode redistribuir? | Pode renderizar ad? |
|---|---|:--:|:--:|
| **Sintetizado (nosso)** | Gerado do zero (risers, bass-drop) | ✅ | ✅ |
| **CC0 (Kenney)** | Domínio público, sem restrição | ✅ | ✅ |
| **Mixkit** | Grátis, sem atribuição, mas **não pode redistribuir o arquivo solto** | ❌ | ✅ |
| **remotion.media** | Biblioteca da Remotion pra vídeos | ❌ | ✅ |
| **viral / famoso** | Música ou meme de áudio protegido | ❌ | 🚫 |

Por isso este repositório **só traz** os arquivos **Sintetizado** e **CC0** — o resto a
gente **aponta a fonte** (ver [FONTES](../fontes/FONTES.md)). Redistribuir Mixkit ou uma
música famosa aqui seria a mesma violação que a gente está ensinando você a evitar.

## Checklist: "posso usar esse som aqui?"

1. **O vídeo vai ser renderizado** (vira um MP4 seu: ad, cliente, YouTube)?
   - **Não, é orgânico pelo app** → pode usar qualquer som, inclusive viral, **adicionando pelo app**.
   - **Sim** → siga pro passo 2.
2. **O som é royalty-free ou seu** (selo ✅ no catálogo)?
   - **Sim** → pode usar. Fim.
   - **Não (selo 🚫)** → **não use renderizado.** Troque por um royalty-free equivalente
     (o catálogo sugere um pra cada momento).

> Regra de bolso: **se sai como um arquivo seu, só som ✅.** Se fica dentro do app, vale tudo.
